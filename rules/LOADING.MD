# Loading States & Skeletons

- **Skeletons**: Skeletons should look like the UI and predict it so that the user expects the UI.
- **Forms**: Forms should be disabled when loading.
- **Spinners**: Spinners can only be used in buttons. Almost everything else should be skeletons that predict the UI.
- **Skeletons for Data**: Skeletons should be for data only, not hard-coded texts.
